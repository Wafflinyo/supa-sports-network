# Official game uploads

Upload each completed Project Rio `.xlsx` game report to this folder in GitHub.
The Pages deployment reads the `Stats` sheet and adds one game played for each
named player row. The pitching sheet does not add another appearance, and team
total rows do not count. Uploading the same exact workbook twice will not add
another game.

Only Games Played is imported for now. Other season stats, scores, and teams
are not imported by this step. The example workbook shared during site design
is not an official game and is not included here.
